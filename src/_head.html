How this works

Snapshots, not live data. OnRe's rewards API rejects requests from browsers, so this page cannot query it live. Every wallet is captured server-side once a day and the whole ledger is built into this one page. It does not update on its own; check the date in the header.

Where the rates come from. Each wallet's daily credit is measured by differencing two full snapshots of every wallet, normalised by the real time between them. Points post in batches, so a wallet whose batch landed outside the window can read as zero for a while.

Projections are arithmetic. They carry today's measured rates forward unchanged. Reward programmes change without notice, so treat every projection as "if today holds", not as a forecast.
